# repaso_3 - Caso Librería Online (Examen Complexivo Práctico)

Solución completa del Examen Complexivo Práctico para el caso de **Librería Online (Sistema Básico de Gestión de Catálogo y Pedidos)**.

## Estructura del Proyecto
- `backend/`: API REST en Django + DRF + PyMongo (`Book` y `Order` en PostgreSQL, `publishers` y `shipping_labels` en MongoDB).
- `frontend/`: Interfaz Web en ReactJS + Vite (`books` y `orders`).
- `movil/`: Aplicación Móvil en React Native + Expo (`publishers` y `shipping-labels`).
- `docs/`: Archivos de evidencia (`comandos.txt` y `evidencia.txt`) para Sistemas Operativos.
- `scripts/`: Scripts DDL/DML de PostgreSQL (`sql_scripts.sql`) y NoSQL MongoDB (`mongo_scripts.js`).
- `GUIA_EVIDENCIAS_COMPLEXIVO.md`: Guía de 30 capturas para Ubuntu Linux.
- `INICIALIZACION_PROYECTOS.md`: Guía de ejecución en 3 terminales.
